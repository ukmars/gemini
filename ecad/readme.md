# ECAD

Here you will find ECAD design files and resources such as part and footprint libraries.

The project will use KiCAD V8.0.x for all Schematic capture and PCB design.

Part datasheets will be stored in a separate folder.


Kicad models for the pico where found [here](https://github.com/ncarandini/KiCad-RP-Pico)
Install instructions [here](https://github.com/ncarandini/KiCad-RP-Pico/blob/main/Install%20instructions.md)
